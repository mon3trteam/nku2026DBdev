## 设计页面

页面对象为“数聚 TeamHub”公共首页，包含：

1. 品牌导航
2. 首屏主信息与主行动
3. 团队数据条
4. 精选项目与最新动态
5. 成员速览
6. 留言转化区

页面原型使用 Axure RP 11 完成，组织为首页、成员页和项目页三页。首页设置导航“成员”、导航“项目”和“查看成员”三个 Hot Spot，分别链接到成员页、项目页和成员页；网页附件用于在浏览器中复核响应式布局与视觉规范。
