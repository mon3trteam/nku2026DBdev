插件测试页

这个页面专门用来演示 网页表格 → SQL 生成器 插件，三张表分别覆盖不同的结构， 用来验证类型推断、表头识别、colspan 展开、空值与转义。

表一：标准结构（有 <caption> 和 <thead>）

最理想的情况：表名能从 caption 取到，列类型应推断为 INTEGER / VARCHAR / INTEGER / REAL。

表二：没有 <thead>，首行是普通 <td>

插件会猜首行是表头并给出提示；勾掉「首行作为表头」后可看到列名退化为 col_1、col_2…
