## 2 已定方案

### 2.1 路由

- 入口：`code/public/index.php`
- 形式：`index.php?r=控制器/动作&参数=值`
- 示例：`index.php?r=member/show&slug=lin-zhiyuan`
- 默认路由：`home/index`
- 控制器文件：`app/controller/{Xxx}Controller.class.php`
- 以后若改路径路由，只改 `app/helpers.php` 里的 `url()` 与 `index.php`，视图不动。

### 2.2 目录

```
code/
├── public/
│   ├── index.php                 # 唯一入口
│   └── static/
│       ├── css/                  # tokens/base/components/public/auth/admin
│       ├── js/                   # common.js
│       ├── img/                  # logo 与占位图
│       └── vendor/bootstrap/     # Bootstrap 5.3.8 本地包
├── app/
│   ├── helpers.php               # e() / url() / asset() / render()
│   ├── controller/               # 每页一个控制器
│   ├── model/                    # 演示数据；后端接入后改方法内部
│   └── view/
│       ├── layout/               # public_header/footer、admin_header/footer
│       ├── partial/              # 成员卡、项目卡、公告条目、技能条
│       ├── public/               # 公共页面
│       ├── auth/                 # 登录
│       ├── admin/                # 后台页面
│       └── error_404.php
└── data/                         # install.sql 等（前端只读）
```

### 2.3 约定

- 所有输出经过 `e()`；不写内联 `<script>`，交互统一放 `static/js/`。
- 控制器只负责取演示数据 + `render()`；视图不查数据、不写业务。
- 演示数据集中在 `app/model/*Model.class.php`，后端接入时只替换方法实现，视图不用改。
- 每个 PHP 文件保留注释头；作者统一写「杨斯源（学号待填）」，提交前补学号。

## 6 后端接入方式

| 现在 | 后端接入后 |
|---|---|
| `MemberModel::allVisible()` 返回静态数组 | 改为查询 `members`，返回同样结构的数组 |
| `TeamModel::profile()` | 查询 `team_profile`（id=1） |
| `AnnouncementModel::all()` | 查询 `v_published_announcements` |
| 登录/留言/审核表单 `action=""` 或占位 | 改为真实路由，加 `csrf_field()`，处理 422/409/429 |
| `url()` 输出 `index.php?r=...` | 若换路径路由，只改 `url()` |
| `asset()` 输出 `/public/static/...` | 站点根指向 `public/` 后改为 `/static/...` |

视图接收的数组字段与设计文档数据字典同名（`slug`、`name`、`role_title`、`published_at` 等），后端按同名字段返回即可。
