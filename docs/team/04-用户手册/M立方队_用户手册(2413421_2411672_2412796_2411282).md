## 1 概述

手册的目标很具体：让第一次访问的人 3 次点击内找到想知道的信息，让第一次登录的成员 10 分钟内改完自己的资料。

### 1.1 编写目的

**核心目的：**　本手册用“怎么做”的方式说明「数聚 TeamHub」的每个页面怎么用：从哪里进入、要填哪些字段、填错会看到什么提示、操作完成后去哪里看结果。它面向使用者而非开发者，因此不解释数据库表结构、不写代码，只描述界面上能看到、能点击、能输入的部分。

- **对访客与评审**：快速了解团队、成员、项目与公告，完成留言或下载。
- **对成员**：独立完成资料维护、头像更换、密码修改，不需要找开发同学。
- **对编辑与管理员**：按统一流程发布内容、审核留言、管理账号，避免误操作。

### 1.2 适用读者

**表 1-1  读者对象与阅读建议**

| 读者 | 常用页面 | 阅读建议 |
| --- | --- | --- |
| 访客 | 首页、团队介绍、成员、项目、公告、资源、留言 | 阅读第 2 章与第 3 章；只想留言的直接看 3.8。 |
| 团队成员 | 成员中心、个人资料、账号安全 | 阅读第 2 章、第 4 章；首次登录先看 4.1 与 4.7。 |
| 内容编辑 | 后台看板、公告/项目/资源管理、留言审核 | 阅读第 5.1—5.8 节；发布前看 5.5 的生命周期说明。 |
| 超级管理员 | 用户与角色、站点设置、日志审计 | 阅读第 5 章全部，重点看 5.9—5.11。 |

### 1.3 手册范围

**范围内：**　公共门户（8 个页面）、成员中心（4 个页面）、管理后台（10 个模块）与下载中心；四类角色的全部操作与常见提示。

**范围外：**　公开注册、第三方登录、在线支付、实时聊天等本期不提供的能力；服务器安装与数据库维护请参阅《部署文档》。

**内容从哪里来：**　系统中的团队资料、成员、项目、公告、留言与资源都不是预置数据，而是通过页面录入生成的。录入入口分两处：后台是内容与成员的创建入口，成员中心是个人资料的维护入口。理解这一点，就能解释“为什么新装的站点是空的”“为什么我把资料改完后公开页立刻变了”。

### 1.4 手册约定

**表 1-2  排版约定**

| 约定 | 含义 |
| --- | --- |
| 「点击 登录」 | 引号内为界面上可见的按钮、菜单或链接文字。 |
| 步骤 1、2、3 | 按顺序执行；有分支时单独说明。 |
| **加粗** | 关键字段名、注意事项或易错点。 |
| `>` 引用块 | 提示、警告或补充说明，不参与操作流程。 |
| 逻辑路径 | 本手册中 `/login`、`/me/profile` 等为逻辑路径缩写；实际访问地址为 `域名/index.php?r=对应路由`，如 `/me/profile` ↔ `index.php?r=me/profile`。完整对照见附录 A 表 7-1。 |
| 表格 | 字段说明、状态对照或错误信息。 |
| * | 表单中的必填标记，未填写无法提交。 |

### 1.5 术语与缩略语

本手册使用的访客、成员、编辑、超级管理员、成员中心、管理后台、Slug、草稿、待审核等术语，已在文档信息页的「术语与缩略语」表中统一解释，正文首次出现时不再重复定义。页面上出现的英文状态（如 `pending`）在 7.3 对照表中有中文解释。

### 1.6 获取帮助

遇到问题时的建议顺序：

1. 先查本手册第 6 章「常见问题」，多数提示语可在 7.3 对照表中找到原因。
2. 页面底部「联系我们」提供团队邮箱，可描述问题并附上页面截图与操作时间。
3. 成员与管理员可通过团队群联系**站点维护同学**，由其在后台日志中按时间与账号定位问题。

## 2 准备工作

在开始操作前，先确认三件事：用什么浏览器、从哪里进入、账号有没有。

### 2.1 访问环境要求

**表 2-1  环境要求**

| 项 | 要求 | 说明 |
| --- | --- | --- |
| 浏览器 | Chrome、Edge、Firefox、Safari 最近两个大版本 | 不建议使用 IE 或内核过旧的国产浏览器兼容模式。 |
| 屏幕宽度 | 360—1440 px 及以上 | 手机、平板、笔记本均可访问；后台表格在窄屏可横向滚动。 |
| 网络 | 能访问站点地址即可 | 静态资源全部本地化，**不依赖外部 CDN**，断外网也能正常显示。 |
| JavaScript | 建议开启 | 图表、筛选与提示需要脚本；关闭后仍可浏览与提交表单。 |
| 账号 | 访客无需账号 | 成员、编辑、管理员账号由超级管理员创建，不开放注册。 |

### 2.2 打开站点

本地演示环境与正式环境的地址不同，以团队通知为准：

**表 2-2  常见访问地址**

| 场景 | 地址 | 说明 |
| --- | --- | --- |
| 本地 Docker 演示 | `http://localhost:8080/` | 一键部署后的默认端口，详见《部署文档》第 4 章。 |
| 校园服务器 / 正式环境 | 团队公布的域名或 IP | 一般已配置 HTTPS，地址以 `https://` 开头。 |

**操作步骤**

1. 在浏览器地址栏输入站点地址并回车。
2. 看到顶部导航（首页、团队介绍、成员、项目、公告、资源）与首屏内容，说明加载成功。
3. 若页面显示「服务暂时不可用」，稍后刷新一次；连续失败请联系维护同学。

> **首次使用**
>
> 刚部署完的站点首页是空状态，因为团队成员与内容还没有录入。请先由超级管理员登录后台建立成员与首条公告，再回到前台查看效果。

### 2.3 账号从哪里来

系统**不提供公开注册**。账号由超级管理员在后台「用户与角色」中创建，创建后通过线下方式告知本人。

**表 2-3  账号相关规则**

| 事项 | 规则 |
| --- | --- |
| 账号形式 | 用户名或邮箱均可用于登录。 |
| 初始密码 | 由管理员生成临时密码，只告知一次。 |
| 首次登录 | 必须修改临时密码后才能进入成员中心。 |
| 忘记密码 | 系统不发送邮件，联系管理员重置临时密码。 |
| 账号禁用 | 被禁用或锁定的账号无法登录，页面提示联系管理员。 |

### 2.4 界面通用元素

三套界面（公共门户、成员中心、管理后台）共享同一套组件，先认识它们可以减少摸索。

**表 2-4  通用元素**

| 元素 | 位置 / 样式 | 作用 |
| --- | --- | --- |
| 顶部导航 | 公共页面上方，移动端折叠为抽屉 | 在首页、团队、成员、项目、公告、资源之间切换；当前页高亮。 |
| 左侧导航 | 成员中心与后台左侧 | 成员中心 4 项；后台按权限显示 10 个模块。 |
| 面包屑 | 后台内容区顶部 | 显示当前位置，可点击上级返回列表。 |
| 主操作按钮 | 页头右侧 | 新建、保存、发布等主要动作。 |
| 筛选栏 | 列表页上方 | 关键词、状态、分类、时间组合筛选。 |
| 分页 | 成员列表底部 | 显示总数与页码，成员列表每页 4 条；后台列表页暂以整页展示为主。 |
| Toast 提示 | 页面右上角，3 秒消失 | 保存成功、操作完成等轻提示。 |
| 二次确认框 | 页面居中浮层 | 删除、下线、归档等危险操作前确认。 |
| 空状态 | 列表区域 | 无数据时显示说明与「新建」或「清除筛选」按钮。 |

> **表单提示**
>
> 带 * 的字段为必填；错误提示紧贴字段下方，红色文字 + 图标同时出现。全部通过校验后提交按钮才会进入加载状态，请勿重复点击。

## 3 访客操作指南

访客无需登录即可完成：了解团队、查看成员与项目、下载作业、提交留言。

### 3.1 浏览首页

首页是第一落点，首屏回答“你们是谁、做过什么、怎么联系”。

**操作步骤**

1. 打开站点地址，进入首页（路径 `/`）。
2. 首屏可看到团队名称、一句话定位与两个按钮：「认识我们 →」进入团队介绍，「查看项目」进入项目列表。
3. 向下滚动依次是：数据条（成员数、项目数、数据表数）、精选项目、最新动态、成员速览、留言入口。
4. 点击任意项目卡片或成员头像，进入对应详情页；点击公告标题进入公告详情。

**表 3-1  首页区块说明**

| 区块 | 内容 | 可做的操作 |
| --- | --- | --- |
| 首屏 | 团队名、口号、定位、2 个按钮 | 进入团队介绍或项目列表。 |
| 数据条 | 成员数、项目数、数据表数、展示维度 | 仅展示，无点击。 |
| 精选项目 | 最多 3 个项目卡片 | 点击卡片进入项目详情。 |
| 最新动态 | 最多 3 条公告 | 点击进入公告详情。 |
| 成员速览 | 最多 4 位成员 | 点击进入成员主页；手机端可横向滑动。 |
| 留言入口 | 一句邀请 + 按钮 | 跳到留言区或 `/messages`。 |

### 3.2 了解团队

点击导航「团队介绍」（路径 `/team`），页面按“故事—时间线—价值观—能力—成员—资料”的顺序展示。

**表 3-2  团队介绍页内容**

| 区块 | 你能看到什么 | 说明 |
| --- | --- | --- |
| 团队故事 | 300—800 字的团队介绍与 1 张配图 | 由后台「团队资料」维护。 |
| 成长时间线 | 3—12 个里程碑（年份、标题、说明） | 鼠标悬停可看说明；手机端纵向排列。 |
| 价值观 | 3—4 张卡片 | 每张标题 + 80 字以内说明。 |
| 能力矩阵 | 技能名、人数、平均熟练度 | 只展示聚合数据，不含个人评分。 |
| 成员网格 | 头像、姓名、角色、技能标签 | 点击进入成员主页。 |
| 资料下载 | 团队作业、设计文档、部署资料 | 跳转到资源下载页。 |

### 3.3 查找成员

**操作步骤**

1. 点击导航「成员」（路径 `/members`）。
2. 在搜索框输入姓名或姓名片段，按回车或等待 0.3 秒自动搜索。
3. 使用「技能」下拉筛选具备某项技能的成员；可再按角色或加入年份排序。
4. 点击成员卡片进入成员主页；点击筛选栏的「清除筛选」恢复全部成员。

> **空结果**
>
> 没有匹配成员时，列表区显示空状态与「清除筛选」按钮，不会出现空白表格。

### 3.4 查看成员主页

成员主页是个人品牌页，地址形如 `/members/{slug}`，例如 `/members/qian-boyu`。

**表 3-3  成员主页区块**

| 区块 | 内容 | 说明 |
| --- | --- | --- |
| 封面与头像 | 16:9 封面、1:1 头像、姓名、英文名 | 头像压在封面上，均有替代文字。 |
| 身份信息 | 团队角色、一句话介绍、所在地、加入时间 | 一句话介绍不超过 60 字。 |
| 社交链接 | GitHub、邮箱、个人网站 | 只显示成员选择公开的链接；邮箱做了混淆处理。 |
| 关于我 | 200—500 字简介 | 支持分段。 |
| 技能矩阵 | 技能名 + 1—5 级进度条 | 按分类分组，最多 12 项。 |
| 代表项目 | 项目卡片（封面、名称、角色、技术栈、成果） | 最多 6 个，更多进入项目列表。 |
| 留言 | 最近 5 条已通过留言 + 留言表单 | 未通过审核的留言不展示。 |

访问被隐藏的成员链接会看到 404 页面，这是正常现象，系统不会提示“该成员存在但不可见”。

### 3.5 浏览项目

**操作步骤**

1. 点击导航「项目」（路径 `/projects`）。
2. 使用筛选栏按状态（规划中、进行中、已完成）或关键词过滤；已归档项目默认不显示，可在筛选中选择「已归档」查看。
3. 点击项目卡片进入详情，可看到正文、技术栈、参与成员与相关项目。
4. 项目详情中的成员卡片可点击，进入对应成员主页。

### 3.6 查看公告

**操作步骤**

1. 点击导航「公告」（路径 `/announcements`）。
2. 置顶公告显示在列表顶部（最多 2 条）；其余按发布时间倒序排列。
3. 点击标题进入公告详情，可看到正文、作者、发布时间与相关公告。
4. 已过期或已下线的公告不会出现在列表中，直接访问其链接会看到 404。

### 3.7 下载作业与文档

下载中心提供两类文件，是课程作业的硬性要求：**团队作业**（6 份团队文档 PDF）与**个人作业**（每人 `作业N(学号_姓名).zip`）。

**操作步骤**

1. 点击导航「资源」（路径 `/resources`）。
2. 在分类中切换「团队作业」「个人作业」「设计文档」「部署资料」「其他」。
3. 每个条目显示标题、文件类型、文件大小与更新时间，点击「下载」开始下载。
4. 浏览器提示保存位置后确认即可；下载次数会自动累加，页面不会刷新。

**表 3-4  资源页字段**

| 字段 | 含义 | 说明 |
| --- | --- | --- |
| 标题 | 文件名称 | 团队文档按「队名_文档名(学号1_学号2_学号3).pdf」展示。 |
| 分类 | 团队作业 / 个人作业 / 设计文档 / 部署资料 / 其他 | 决定筛选项。 |
| 文件类型与大小 | 如 PDF · 1.2 MB | 便于下载前判断。 |
| 更新时间 | 最近一次替换时间 | 同名文件更新后时间会变化。 |
| 可见性 | 公开 / 仅成员 | 仅成员可见的资源需登录后才能下载。 |

> **下载失败怎么办**
>
> 若点击后提示「文件不存在」，说明该文件尚未放入 `data/team/` 或 `data/personal/` 对应目录；若提示「没有权限」，说明该资源未公开，请登录成员账号或联系管理员。

### 3.8 提交留言

留言是访客与团队建立联系的最低门槛方式。**留言提交后不会立即公开**，需管理员审核通过。

**操作步骤**

1. 进入成员主页的留言区，或点击导航「留言」（路径 `/messages`）。
2. 填写表单：昵称、邮箱（可选）、个人网站（可选）、目标成员（可选）、留言内容。
3. 勾选「我已知晓留言需审核，邮箱不会公开」。
4. 点击「提交留言」，看到「提交成功，审核后展示」的提示即完成。

**表 3-5  留言字段与规则**

| 字段 | 必填 | 规则 | 说明 |
| --- | --- | --- | --- |
| 昵称 | 是 | 2—30 字 | 公开展示，可用网名。 |
| 邮箱 | 否 | 需为合法邮箱格式 | **不公开**，仅管理员可见。 |
| 个人网站 | 否 | 只允许 `http://` 或 `https://` 开头 | 公开展示为链接。 |
| 目标成员 | 否 | 从成员列表选择 | 不选则进入公共留言板。 |
| 留言内容 | 是 | 10—500 字 | 不支持上传附件与 HTML 标签。 |

**提交限制**

- 同一 IP 10 分钟内最多提交 5 条，超出会提示「提交过于频繁，请 10 分钟后再试」。
- 留言中的外部链接数量会作为人工审核的辅助参考，不自动拦截。

### 3.9 常见提示与错误

**表 3-6  访客常见提示**

| 提示 | 原因 | 处理方式 |
| --- | --- | --- |
| 页面或资源不存在（404） | 链接过期、内容下线、成员被隐藏 | 返回首页或用导航重新查找。 |

| 服务暂时不可用（500） | 数据库或服务异常 | 稍后刷新；持续出现请联系维护同学。 |

## 4 成员操作指南

成员登录后可在成员中心维护自己的公开资料：改一次，成员主页、成员列表与首页成员速览同时更新。

### 4.1 登录

**操作步骤**

1. 点击右上角「登录」，进入 `/login`。
2. 输入用户名或邮箱、密码；可点击密码框右侧的「显示」确认输入无误。
3. 点击「登录」。成功后自动跳转：成员进入 `/me`，编辑与管理员进入 `/admin`。
4. 若之前访问的是受保护页面，登录后会自动回到该页面。

**表 4-1  登录异常与处理**

| 页面提示 | 原因 | 处理方式 |
| --- | --- | --- |
| 用户名或密码不正确 | 账号不存在或密码错误（系统不区分两者） | 核对后重试；忘记密码联系管理员重置。 |
| 账号不可用，请联系管理员 | 账号被禁用或锁定 | 联系超级管理员解除。 |
| 尝试次数过多，请稍后再试 | 连续 5 次密码错误，锁定 15 分钟 | 等待倒计时结束再登录。 |
| 首次登录需修改密码 | 使用的是管理员下发的临时密码 | 按提示设置新密码后继续。 |

> **安全提示**
>
> 连续 5 次输错密码会锁定账号 15 分钟，锁定期内即使密码正确也无法登录。请勿在公共电脑上勾选“记住密码”，使用完毕后按 4.8 退出登录。

### 4.2 成员中心概览

登录后默认进入 `/me`。概览页显示资料完整度、最近参与的项目与常用快捷入口。

**表 4-2  概览页内容**

| 区块 | 内容 | 可做的操作 |
| --- | --- | --- |
| 资料完整度 | 0—100% 的进度条与缺失项提示 | 点击跳转到对应字段。 |
| 快捷入口 | 个人资料、我的项目、账号安全 | 进入对应页面。 |
| 最近项目 | 与本人关联的项目 | 点击进入项目详情。 |
| 公开主页入口 | 「查看公开主页」链接 | 新开窗口查看别人看到的样子。 |

> **第一次登录**
>
> 新成员的资料是空白的，公开主页会显示引导状态。按 4.3 补全姓名、角色、一句话介绍、头像与至少 3 项技能后，公开主页即可正常展示。

### 4.3 编辑个人资料

**操作步骤**

1. 从左侧导航进入「个人资料」（路径 `/me/profile`）。
2. 按分组修改：基本资料、联系方式、头像与封面、技能标签。
3. 每组字段有独立校验，错误提示显示在字段下方；修正后提示自动消失。
4. 点击底部「保存修改」，看到「保存成功」提示即完成。
5. 点击右上角「查看公开主页」，确认展示效果符合预期。

**表 4-3  个人资料字段与校验**

| 字段组 | 字段 | 规则 | 展示位置 |
| --- | --- | --- | --- |
| 基本资料 | 姓名 | 2—30 字，必填 | 成员主页头部、成员列表。 |
| 基本资料 | 英文名 | 选填，仅用字母、空格与连字符 | 成员主页头部。 |
| 基本资料 | 公开 slug | 3—60 位，小写字母、数字、连字符，全局唯一 | 形成 `/members/{slug}` 链接。 |
| 基本资料 | 团队角色 | 不超过 20 字 | 成员主页身份区。 |
| 基本资料 | 一句话介绍 | 不超过 60 字 | 成员主页身份区、成员卡片。 |
| 基本资料 | 个人简介 | 不超过 500 字，可分段 | 成员主页「关于我」。 |
| 基本资料 | 所在地 | 选填 | 成员主页身份区。 |
| 基本资料 | 加入日期 | 只读，由管理员维护 | 成员主页身份区。 |
| 联系方式 | 邮箱 | 合法邮箱格式；默认不公开 | 成员主页社交区（成员选择公开后显示）。 |
| 联系方式 | GitHub / 个人网站 | 只允许 `http://` 或 `https://` | 成员主页社交区。 |
| 头像与封面 | 头像 | JPG/PNG/WebP，建议 400×400，≤ 2 MB | 成员主页头部、成员列表。 |
| 头像与封面 | 封面 | JPG/PNG/WebP，建议 1600×900，≤ 5 MB | 成员主页顶部。 |

> **并发编辑**
>
> 如果两位同学同时编辑同一份资料，后保存的一方会看到「资料已被他人修改，请刷新后重试」。这是为了防止覆盖他人修改：刷新页面、重新填写后再保存即可。

### 4.4 更换头像与封面

**操作步骤**

1. 在「个人资料」页面点击头像或封面上的「更换」。
2. 选择本地图片，确认裁剪比例（头像 1:1、封面 16:9）。
3. 点击「上传」，等待进度完成并出现预览。
4. 点击「保存修改」后对公开页面生效。

**表 4-4  上传限制**

| 类型 | 支持格式 | 建议尺寸 | 大小上限 | 失败提示 |
| --- | --- | --- | --- | --- |
| 头像 | JPG、PNG、WebP | 400×400（1:1） | 2 MB | 图片格式不支持 / 图片过大 |
| 封面 | JPG、PNG、WebP | 1600×900（16:9） | 5 MB | 图片格式不支持 / 图片过大 |

### 4.5 维护技能标签

1. 在「个人资料」页找到「技能标签」区块，点击「添加技能」。
2. 从技能库下拉中选择技能（成员不能自行新增全局技能，需管理员维护）。
3. 用 1—5 选择熟练度：1 为了解、2 为入门、3 为熟练、4 为精通、5 为专家级。
4. 每人最少 3 项、最多 12 项；删除时点击标签上的「×」。
5. 点击「保存修改」后，成员主页技能矩阵与团队能力矩阵同步更新。

### 4.6 查看我的项目

1. 左侧导航进入「我的项目」（路径 `/me/projects`）。
2. 列表只显示与本人关联的项目，可看到自己在项目中的角色与贡献说明。
3. 可修改「我的角色」与「贡献说明」；**项目主体信息**（标题、封面、状态等）只能由管理员在后台修改。
4. 点击项目名可跳转到公开的项目详情页。

### 4.7 修改密码

**操作步骤**

1. 左侧导航进入「账号安全」（路径 `/me/security`）。
2. 输入当前密码、新密码、确认新密码。
3. 点击「保存」，成功后会提示「密码已修改，请重新登录」。
4. 修改成功后其它设备上的旧会话自动失效，需要重新登录。

**表 4-5  密码规则**

| 规则 | 要求 |
| --- | --- |
| 长度 | 至少 10 位 |
| 复杂度 | 大写字母、小写字母、数字、符号中至少包含 3 类 |
| 禁止 | 不得与用户名相同 |
| 二次确认 | 新密码需连续输入两次且完全一致 |
| 生效范围 | 修改成功后旧会话失效，需在所有设备重新登录 |

### 4.8 退出登录

点击右上角账号菜单中的「退出登录」。系统使用 POST 请求退出，退出后返回首页，登录态立即失效。公共电脑上请务必退出，不要仅关闭标签页。

## 5 管理后台操作指南

后台面向编辑与超级管理员，路径前缀 `/admin`。后台以效率为目标：左侧固定导航、顶部面包屑、列表统一支持筛选与批量操作。

### 5.1 进入后台与权限

**操作步骤**

1. 使用编辑或管理员账号登录，系统自动跳转 `/admin`。
2. 左侧导航只显示当前角色有权访问的模块；没有权限的模块不会出现。
3. 直接输入无权限的地址会看到 403 页面，这是正常的权限控制，不是故障。

**表 5-1  角色与后台权限**

| 模块 | 成员 | 编辑 | 超级管理员 |
| --- | --- | --- | --- |
| 数据看板 | — | ✓ | ✓ |
| 团队资料 / 站点设置 | — | 团队资料 | ✓ |
| 成员管理 | — | ✓ | ✓ |
| 公告 / 项目 / 资源管理 | — | ✓ | ✓ |
| 留言审核与回复 | — | ✓ | ✓ |
| 数据包（导出/导入） | — | — | ✓ |
| 用户与角色 | — | — | ✓ |
| 日志审计 | — | — | ✓ |

> **初始化顺序**
>
> 系统安装完成后自带 6 个初始账号（admin / editor / member1~4，初始密码见 install.sql 文件头）与技能字典数据。建议按「团队资料 → 成员 → 账号绑定 → 项目 → 公告 → 资源」的顺序录入，前台页面才会逐步充实；成员的个人资料由成员本人登录后维护。

### 5.2 数据看板

登录后台的默认页，用于快速判断站点运行情况。

**表 5-2  看板指标**

| KPI / 图表 | 含义 | 点击行为 |
| --- | --- | --- |
| 成员总数 | 可见成员数量，附本月新增 | 进入成员列表。 |
| 已发布项目 | 进行中与已完成且可见的项目数 | 进入项目列表。 |
| 待审核留言 | 状态为待审核的留言数 | 进入留言管理并筛选待审核。 |
| 近 7 日访问 | 按访客去重的访问量 | 进入访问统计（需权限）。 |
| 访问趋势 | 近 14 天每日访问量与访客数 | 切换 7/14/30 天。 |
| 留言状态分布 | 待审核/已通过/已拒绝/垃圾占比 | 点击扇区筛选用留言列表。 |
| 技能分布 | 各技能分类的成员数 | 横向柱状图，适合中文标签。 |
| 项目状态 | 规划/进行/完成/归档数量 | 堆叠柱状图。 |

图表数据每 60 秒自动刷新；发布或审核操作后立即刷新。若图表区域显示为表格，说明图表脚本未加载，数据仍可正常查看。

### 5.3 维护团队资料

1. 左侧导航进入「团队资料」（路径 `/admin/team`）。
2. 修改团队名称、英文名、口号、简介、故事、成立时间、所在地、联系方式、Logo、封面、社交链接与价值观。
3. 点击「保存」，首页与团队介绍页同步更新。

**表 5-3  团队资料要点**

| 项 | 规则 |
| --- | --- |
| 团队故事 | 300—800 字，可分 2—3 段 |
| 价值观 | 最多 6 张卡片（标题留空的行不保存），每张说明不超过 80 字 |
| 社交链接 | 只允许 `http://`、`https://` |
| 单例约束 | 团队资料只有一份，修改是覆盖而不是新增 |

### 5.4 成员管理

**操作步骤**

1. 进入「成员管理」（路径 `/admin/members`）。
2. 列表展示头像、姓名、团队角色、关联账号、精选/可见状态、资料完整度与排序值。
3. 使用搜索与筛选定位成员；显示顺序在成员编辑表单中以「排序值」调整（数字越小越靠前）。
4. 编辑成员时可同步创建或绑定登录账号，并设置「可见」「精选」开关。
5. 删除成员采用**归档**而非物理删除，历史项目与留言关联保留。

**表 5-4  成员管理操作**

| 操作 | 效果 | 注意 |
| --- | --- | --- |
| 编辑 | 修改成员公开资料 | 可见/精选开关影响前台展示。 |
| 绑定账号 | 为该成员创建或绑定登录账号 | 一个成员档案最多绑定一个账号。 |
| 归档 | 从前台移除，保留关联数据 | 需二次确认。 |
| 排序 | 调整成员列表顺序 | 排序值越小越靠前。 |

### 5.5 公告管理

公告按「草稿 → 发布 → 下线 → 归档」的生命周期管理。

**操作步骤**

1. 进入「公告管理」（路径 `/admin/announcements`），点击「新建公告」。
2. 填写标题、slug、摘要、正文、封面、分类；可选设置置顶、发布时间与过期时间。
3. 先「保存草稿」并「预览」，确认无误后点击「发布」。
4. 发布后公告出现在首页「最新动态」与公告中心；可随时「下线」或「归档」。

**表 5-5  公告字段与规则**

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 标题 | 是 | 不超过 80 字 |
| slug | 是 | 小写字母、数字、连字符，全局唯一 |
| 摘要 | 否 | 不超过 200 字，用于列表展示 |
| 正文 | 是 | 受限 Markdown，不允许原始 HTML |
| 封面 | 否 | JPG/PNG/WebP，≤ 5 MB |
| 置顶 | 否 | 最多同时置顶 2 条，超出自动取消最早的置顶 |
| 发布时间 / 过期时间 | 发布时必填 | 过期后自动从公开列表移除 |

> **发布前必做**
>
> 公告正文只支持受限 Markdown，粘贴 Word 或网页内容时请先转为纯文本再排版，否则可能出现乱码或多余标签。

### 5.6 项目管理

1. 进入「项目管理」（路径 `/admin/projects`），点击「新建项目」。
2. 填写标题、slug、摘要、正文、封面、技术栈、状态、起止时间，并至少关联 1 名成员。
3. 可设置「推荐」让项目出现在首页精选位置。
4. 保存后可在列表中批量推荐或归档；归档项目默认不在前台展示。

**表 5-6  项目字段与规则**

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 标题 / slug | 是 | slug 全局唯一 |
| 成员 | 是 | 至少 1 名，可设置成员角色与贡献说明 |
| 状态 | 是 | 规划中、进行中、已完成、已归档 |
| 技术栈 | 否 | 逗号分隔，最多 10 项 |
| 起止时间 | 否 | 结束时间不得早于开始时间 |

### 5.7 留言审核与回复

留言默认进入「待审核」，审核通过后才在前台公开。

**操作步骤**

1. 进入「留言管理」（路径 `/admin/messages`），默认筛选「待审核」。
2. 列表显示访客昵称、内容摘要、目标成员、提交时间与状态。
3. 点击某条留言查看详情：完整内容、邮箱（仅管理员可见）、脱敏 IP 哈希。
4. 选择「通过」「拒绝」或「标记垃圾」；可同时填写回复内容。
5. 支持批量通过或批量拒绝，执行后显示成功与失败数量。

**表 5-7  留言状态与操作**

| 当前状态 | 可执行操作 | 结果 |
| --- | --- | --- |
| 待审核 | 通过 | 进入公开区，按时间展示。 |
| 待审核 | 拒绝 | 不公开，记录保留。 |
| 待审核 | 标记垃圾 | 加入反垃圾样本，不公开。 |
| 已拒绝 | 复核通过 | 重新公开，记录复核人。 |
| 已通过 | 标记垃圾 | 立即从公开区移除。 |

> **误操作可挽回**
>
> 审核操作都会记录操作者、时间与前后状态。若误判，可在列表中使用「复核」改回，无需删除留言；只有超级管理员可以物理删除违规或测试数据，且会留下审计快照。

### 5.8 资源管理

1. 进入「资源管理」（路径 `/admin/resources`），点击「上传资源」。
2. 填写标题、选择分类（团队文档、个人作业、设计资料、部署资料、其他）、填写说明。
3. 选择文件上传，系统会校验格式与大小；通过后显示文件类型与大小。
4. 设置「公开」或「仅成员」，保存后资源出现在前台下载中心。

**表 5-8  资源上传规则**

| 校验项 | 规则 |
| --- | --- |
| 文件格式 | 团队文档 / 设计资料为 PDF；个人作业为 zip；图片为 JPG/PNG/WebP |
| 文件大小 | 单文件不超过 10 MB（表单为单文件上传） |
| 命名 | 系统随机化文件名；展示名使用标题 |
| 计数 | 每次成功下载自动 +1，可在列表查看 |

### 5.9 用户与角色

仅超级管理员可见。

**操作步骤**

1. 进入「用户与角色」（路径 `/admin/users`）。
2. 点击「新建账号」，填写用户名、邮箱、显示名，选择角色，系统生成临时密码。
3. **临时密码只显示一次**，请立即复制并线下告知本人。
4. 需要时可「重置密码」「禁用账号」或「修改角色」；角色修改在对方下一次请求时生效。

**表 5-9  账号操作**

| 操作 | 说明 | 注意 |
| --- | --- | --- |
| 新建账号 | 创建成员、编辑或管理员账号 | 不开放公开注册，只能由管理员创建。 |
| 重置密码 | 生成新的临时密码 | 只显示一次；对方下次登录必须改密。 |
| 禁用账号 | 立即阻止登录 | 会话在下一次请求时失效。 |
| 修改角色 | 一个账号只分配一个角色 | 变更写审计日志。 |
| 解除锁定 | 清除连续失败导致的锁定 | 仅超级管理员可操作。 |

### 5.10 站点设置

1. 进入「站点设置」（路径 `/admin/settings`）。
2. 修改站点名称、SEO 描述、页脚文案、备案信息与维护模式。
3. 保存后前台 5 分钟内生效（缓存刷新）。
4. 开启「维护模式」时，访客看到维护提示，管理员仍可登录后台。

### 5.11 日志审计

1. 进入「日志审计」（路径 `/admin/logs`）。
2. 切换「登录日志」与「操作审计」两个标签。
3. 按账号、动作、时间范围筛选；列表只读，不提供修改与删除。
4. 记录中的 IP 均以脱敏哈希形式展示（不保存明文 IP）。

**表 5-10  日志类型**

| 日志 | 记录内容 | 保留期 |
| --- | --- | --- |
| 登录日志 | 账号、成功/失败、原因、脱敏 IP 哈希、浏览器信息 | 180 天 |
| 操作审计 | 操作者、动作、实体、修改前后快照 | 180 天 |

## 6 常见问题

以下问题按使用频率排序，先查表再联系维护同学。

### 6.1 登录与账号

**表 6-1  登录与账号问题**

| 问题 | 原因 | 解决方法 |
| --- | --- | --- |
| 一直没有收到账号 | 账号需管理员手动创建，系统不发邮件 | 联系超级管理员创建并获取临时密码。 |
| 提示「用户名或密码不正确」 | 账号不存在或密码错误，系统统一提示以防账号枚举 | 核对大小写与输入法；仍失败请重置密码。 |
| 刚登录就被退出 | 会话空闲超过 30 分钟自动失效 | 重新登录；需要长时间编辑时先保存草稿。 |
| 改完密码后其它设备要重新登录 | 改密会使旧会话失效，属于安全设计 | 在新设备上重新登录即可。 |
| 账号被锁定 | 连续 5 次密码错误，锁定 15 分钟 | 等待倒计时结束，或请超级管理员解除锁定。 |

### 6.2 资料与上传

**表 6-2  资料与上传问题**

| 问题 | 原因 | 解决方法 |
| --- | --- | --- |
| 保存时提示「资料已被他人修改」 | 多人同时编辑，后保存者触发冲突保护 | 刷新页面，重新填写后保存。 |
| 头像上传失败 | 格式或大小不符合要求 | 转为 JPG/PNG、控制在 2 MB 内、比例 1:1。 |
| 封面显示被裁切 | 图片比例不是 16:9 | 用 1600×900 重新导出后上传。 |
| slug 提示已被占用 | slug 全局唯一 | 换一个更具体的写法，如加上专业或年份。 |
| 技能无法新增 | 成员不能创建全局技能 | 联系管理员在技能库中添加。 |
| 公开主页看不到刚改的内容 | 未点击「保存修改」，或浏览器缓存 | 保存后刷新公开主页；再不行请清除缓存。 |

### 6.3 留言与内容

**表 6-3  留言与内容问题**

| 问题 | 原因 | 解决方法 |
| --- | --- | --- |
| 留言提交后看不到 | 留言需审核通过才公开 | 等待审核，通常 1 个工作日内处理。 |
| 提示「操作过于频繁」 | 同一 IP 每小时最多 3 条留言 | 稍后再试或换网络环境。 |
| 留言被标记为垃圾 | 内容含大量链接或敏感词 | 精简内容后重新提交，或联系管理员复核。 |
| 公告发布后首页没变化 | 首页缓存 60 秒，或发布时间设置为未来 | 等待 1 分钟刷新；检查发布时间。 |
| 正文里的 HTML 标签被显示为文字 | 正文只支持受限 Markdown，不支持原始 HTML | 改用 Markdown 语法排版。 |
| 首页看起来是空的 | 团队与成员内容尚未录入 | 由管理员按 5.1 的初始化顺序录入内容。 |

### 6.4 显示与兼容性

**表 6-4  显示与兼容性问题**

| 问题 | 原因 | 解决方法 |
| --- | --- | --- |
| 图表区域是空白 | 脚本被拦截或未加载 | 关闭广告拦截插件；页面会以表格兜底显示数据。 |
| 手机上表格被截断 | 后台表格支持横向滚动 | 左右滑动表格，或改用平板/电脑操作。 |
| 页面字体很小 | 浏览器缩放比例异常 | 按 `Ctrl` + `0`（Mac 为 `Command` + `0`）重置缩放。 |
| 提示「页面或资源不存在」 | 内容已下线、成员被隐藏或链接过期 | 通过导航重新进入。 |
